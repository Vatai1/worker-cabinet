# Changelog

## 2.4.9 — 2026-09-25
- Страница отпусков сохраняет в URL выбранный год, вкладку и фильтры (календарь и согласование) — ссылкой можно поделиться, после перезагрузки всё на месте; при смене организации фильтры из URL не применяются
- Ссылка из уведомления больше не переоткрывает карточку заявки при каждой смене фильтра
- WebSocket (счётчик уведомлений и живой календарь отпусков) снова работает при входе через Keycloak
- WebSocket больше не переподключается бесконечно при отказе в авторизации; при обрывах пауза между попытками растёт до минуты
- Тёмная тема и включение push-уведомлений хранятся в браузере (localStorage), отдельно для каждого устройства; выбранная ранее тема переносится автоматически

## 2.4.8 — 2026-09-25
- Изменение дней отпуска сразу действует на будущие годы: правила «Дни отпуска» пересчитывают балансы текущего и следующих лет, правка «Всего дней» в карточке работника меняет выбранный год и все последующие (баланс на следующий год создаётся сразу)
- В «Днях отпуска» появилась модалка «Изменить правило»: можно менять число дней, добавлять и убирать должности или работников в правиле

## 2.4.7 — 2026-09-25
- Праздники в отпуске больше не сдвигают дату окончания: даты остаются как выбраны, праздничные дни просто не входят в число дней отпуска
- Пересечения отпусков: вместо выбора отдела — список «моих сотрудников» (руководитель — свой отдел, HR/админ — вся организация); выбор тега открывает дополнительный список всех работников организации с этим тегом; ограничение можно создать от одного человека
- Пересечения: у ограничения подписан владелец, изменять и удалять его может только владелец или HR; в «Текущих ограничениях» — ограничения с моими сотрудниками и мои собственные
- Текущие пересечения показывают только текущие и будущие отпуска и только сотрудников руководителя
- Модалка создания правила пересечения у HR переделана под ту же форму; в колонке «Отдел» — отделы участников, «Все отделы» только у правил по тегам
- Таблица «Работники отдела» в календаре фильтруется по выбранному тегу
- Ошибки API пишутся в журнал ошибок для всех пользователей вместе с причиной и stack; вместо «An error occurred» показывается понятное описание ошибки, сообщения переведены на русский
- При истёкшей или отозванной сессии сразу выкидывает на страницу входа, не дожидаясь перезагрузки
- Одновременное обновление токена в нескольких вкладках больше не разлогинивает (льготный период 30 секунд для только что сменённого refresh-токена)
- Починены presigned-ссылки на скриншоты при фронте и бэкенде на разных серверах: nginx передаёт MinIO тот же Host, с которым подписана ссылка
